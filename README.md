# Druxio

**Freelance marketplace platform with only 5% platform fee.**

Hire verified professionals or offer your services across tech, design, content, business and more. Secure escrow payments, AI-powered matching, and a full messaging system.

## Live

[druxio.net](https://druxio.net)

## Stack

- **Frontend** — React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend** — Supabase (Auth, Database, Edge Functions, Realtime)
- **Payments** — PayPal, Stripe
- **AI** — OpenAI (matching, chat, session summaries)
- **Email** — Resend

## Features

- Post a request and get quotes from professionals in minutes
- Only 5% platform fee (vs 20–30% on Upwork/Fiverr)
- Escrow-protected milestone payments
- Real-time inbox and session chat
- AI-powered expert matching
- Referral system and wallet
- Admin dashboard with moderation tools

## Local Development

```bash
git clone https://github.com/gekk0playz/druxio.git
cd druxio
npm install
npm run dev
```

Requires a `.env` file with your Supabase project URL and anon key.
